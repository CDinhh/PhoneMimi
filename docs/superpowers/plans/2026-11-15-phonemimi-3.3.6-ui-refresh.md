# PhoneMimi 3.3.6 UI Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship PhoneMimi 3.3.6: Lucide icons, Plus Jakarta Sans, penguin "polar night" waiting screen, new toggles/segments with a selectable accent colour (blue default), restyled Add Android panel, own GitHub repo and a PhoneMimi README.

**Architecture:** Fonts (Lucide + Plus Jakarta Sans) and the logo are embedded in the exe as RCDATA and registered privately at startup (`AddFontMemResourceEx`), so the existing GDI text path and `draw_glyph()` keep working with new font names. A small set of shared drawing helpers (shell, toggle, segment, field, pill button) in `renderer.cpp` replaces the per-panel lambdas so Settings and Add Android look the same. Accent colour is one `Settings` field mapped to a fixed 6-entry palette.

**Tech Stack:** C++20, SDL2, GDI text rendering, stb_image, CMake, GitHub Actions (`release.yml`), `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-11-15-phonemimi-3.3.6-ui-refresh-design.md` (approved mockup: https://claude.ai/artifact/4aS1u9U5FYkTVDbxTb3WjJ — where spec and mockup differ, the mockup wins).

## Global Constraints

- No local C++ toolchain: every build is `gh workflow run release.yml -R <repo> --ref <branch>`, then `gh run download <id> -n PhoneMimi-3.3.6-portable`; check `PhoneMimi.exe --srp-self-test` prints `roundtrip: PASS`.
- One CI build per batch (after Task 5, again after Task 7 on the new repo) — not one per task.
- Strings in code stay ASCII. Commit messages English, no AI trailers. Work on branch `feat/ui-refresh-3.3.6`; never commit to `main` directly.
- Pinned assets: `lucide-static@0.469.0` (`font/lucide.ttf`), Plus Jakarta Sans `tokotype/PlusJakartaSans@2.7.1` static TTFs Medium, SemiBold, Bold, ExtraBold.
- Accent palette (index: name base light ink): 0 Blue `#2563EB` `#4F8EF7` white · 1 Sky `#0EA5E9` `#38BDF8` dark · 2 Violet `#7C3AED` `#9F67FF` white · 3 Green `#22C55E` `#4ADE80` dark · 4 Pink `#DB2777` `#F0529C` white · 5 Orange `#F07F2E` `#FF9C55` dark. Dark ink = `#0B0E14`.
- Version is set only in `CMakeLists.txt` `project(... VERSION 3.3.6 ...)` plus a README version-history row.
- Never block the SDL thread; animations advance per frame from `steady_clock`.
- Keep GPL: `LICENSE` stays, README credits MSEndpointMgr/1PhoneMirror.

## Review Focus

1. Embedded font fails to register (resource missing, `AddFontMemResourceEx` returns 0) → text falls back to Segoe UI and icons to Segoe Fluent/MDL2; nothing renders as boxes. (Task 1, fallback in `ui_font_name()` / `icon_font_name()`.)
2. `settings.ini` holds `accent_color=99`, `-1` or `abc` → app uses Blue and rewrites a valid value on next save. (Task 3, clamp in `Settings::load`.)
3. A toggle clicked twice quickly → knob reverses from where it is, never jumps. (Task 3, animation state per toggle.)
4. Small window / high DPI → Settings and Add Android panels still fit inside the phone screen; icons scale with the panel unit. (Tasks 3-4, sizes derived from `ui_ref_width()`.)
5. In-app version panel (`V`) still lists versions from the rewritten README table. (Task 6.)
