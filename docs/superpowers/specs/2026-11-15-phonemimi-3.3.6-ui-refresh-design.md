# PhoneMimi 3.3.6: làm mới giao diện + repo riêng

Ngày: 15/11/2026. Người duyệt: Định.

## Vì sao
App đã đổi tên thành PhoneMimi nhưng giao diện, icon, README và repo vẫn mang dấu vết của bản gốc
1PhoneMirror. Định muốn một app trông "của mình": icon đẹp, công tắc đẹp, bảng thêm Android
không còn xấu, repo tên PhoneMimi và không hiện là fork.

## Mục tiêu
1. Bỏ icon loa "Mute audio (U)" ở viền trái (đã có nút mute lồi bên hông). Phím `U` vẫn giữ.
2. Logo cánh cụt thay cho vòng tròn xanh + icon điện thoại ở màn hình chờ.
3. Version 3.3.6.
4. Toàn bộ icon chuyển sang **Lucide** (Định chọn).
5. Công tắc (toggle) và nút chọn (segment) trong Settings làm lại cho đẹp.
6. Bảng "Add Android phone" làm lại cùng phong cách với Settings.
7. Repo mới `CDinhh/PhoneMimi`, README viết lại, chỉ ghi một dòng nguồn gốc fork.

## Không làm
- Không đổi bố cục khung điện thoại, nút hông, drawer.
- Không đổi chức năng, phím tắt, giao thức.
- Không đụng bản Rust.

## Phản mục tiêu (làm thế này là hỏng dù chạy được)
- Hai bảng (Settings, Add Android) mỗi bảng một kiểu.
- Còn sót icon Segoe hoặc icon vẽ tay lẫn với Lucide.
- Còn chữ giải thích thừa kiểu AI trên giao diện.
- Animation chặn luồng UI hoặc giật.
- Bảng lịch sử version (`V`) trong app không đọc được README mới.

## Ràng buộc
- C++/SDL2, UI vẽ tay trong `src/media/renderer.cpp`; chữ/icon vẽ qua GDI (`make_text_texture_w`
  với tên font), icon hiện tại qua `draw_glyph()` + font Segoe Fluent Icons.
- Không có bộ build tại máy: build bằng GitHub Actions (~4 phút khi có cache).
- Chuỗi trong code phải ASCII.
- GPL-3.0: giữ LICENSE và ghi công tác giả gốc.

## Các cách đã cân nhắc

**Icon Lucide**
- (Chọn) **Font Lucide** (`lucide-static`, file `lucide.ttf`, ghim phiên bản) nhúng vào exe dạng
  RCDATA, nạp bằng `AddFontMemResourceEx` lúc khởi động; `icon_font_name()` trả về "lucide".
  `draw_glyph()` giữ nguyên, chỉ đổi mã ký tự. Ít code nhất, không cần file rời.
- SVG Lucide rasterize sẵn thành ảnh PNG: chỉnh được độ dày nét nhưng phải thêm bước sinh ảnh và
  nhiều code nạp texture. Bỏ.
- Vẽ lại icon bằng đường kẻ SDL: nét răng cưa, nhiều code. Bỏ.

Ghi chú: skill high-end-visual-design cấm "Lucide nét dày". Lucide font có nét 2px cố định; để
trông mảnh, icon vẽ ở độ trong 85-90% và kích thước vừa phải. Định đã chọn Lucide nên giữ.

**Repo**
- (Chọn) **Tạo repo mới** `CDinhh/PhoneMimi` (public), push toàn bộ lịch sử + branch. Remote:
  `origin` = PhoneMimi, `upstream` = MSEndpointMgr/1PhoneMirror; repo fork cũ archive (không xóa).
  Ngay lập tức, không phải chờ GitHub Support.
- Nhờ GitHub Support tách fork: giữ được tên cũ/sao, nhưng chờ vài ngày và phải tự gửi form. Bỏ.

**Logo**
- (Chọn) Nhúng `resources/logo.png` vào exe (RCDATA) và giải mã bằng `stbi_load_from_memory`;
  không phụ thuộc file rời cạnh exe.

## Thiết kế

### Bản mẫu đã duyệt (15/11)
Mẫu HTML Định đã chốt: https://claude.ai/artifact/4aS1u9U5FYkTVDbxTb3WjJ (3 màn: màn hình chờ,

### Màu nhấn (accent)
- Mặc định **xanh dương** `#2563EB` (sáng `#4F8EF7`).
- Setting mới `accent_color` (settings.ini, mặc định 0) chọn 1 trong 6 màu, dòng "Accent colour" ở
  tab General ngay dưới "Frame colour":
  Blue `#2563EB`/`#4F8EF7` chữ trắng · Sky `#0EA5E9`/`#38BDF8` chữ tối · Violet `#7C3AED`/`#9F67FF`
  chữ trắng · Green `#22C55E`/`#4ADE80` chữ tối · Pink `#DB2777`/`#F0529C` chữ trắng ·
  Orange `#F07F2E`/`#FF9C55` chữ tối.
- Màu nhấn dùng cho: công tắc bật, viên segment đang chọn (viền), nút chính, viền focus ô nhập,
  chấm "bắt buộc", nút island đang bật, chấm loading màn hình chờ, ô icon Android.

### Font chữ
- Nhúng **Plus Jakarta Sans** (OFL, các độ đậm 500/600/700/800) vào exe như font Lucide, dùng cho
  toàn bộ chữ giao diện thay Segoe UI.

### Hệ thống chung (dùng cho Settings + Add Android)
- Một nhóm hàm vẽ dùng chung (thay cho lambda riêng trong từng bảng): `ui_surface`, `ui_toggle`,
  `ui_segment`, `ui_field`, `ui_button`, đặt ở `renderer.cpp`.
- Kiểu "double bezel": vỏ ngoài có viền mảnh sáng (trắng ~8%), lõi trong tối hơn với một đường
  sáng 1px ở mép trên; bo góc đồng tâm.
- Mọi chỗ "bật"/"chính" dùng màu nhấn đang chọn (mục trên).

### Công tắc
- Rãnh lõm: viền ngoài mảnh + nền tối, khi bật nền chuyển dần sang xanh lá.
- Núm tròn trắng có bóng mờ nhẹ phía dưới và đường sáng phía trên.
- Bật/tắt có animation lò xo ~250 ms (núm trượt + đổi màu), trạng thái animation lưu theo từng
  công tắc; hover sáng nhẹ.

### Nút chọn (segment)
- Rãnh lõm, "viên" đã chọn trượt sang vị trí mới với cùng đường cong lò xo.

### Bảng Add Android phone

```
 │  Add Android phone      (?) (x)│
 │  ┌ Nearby ──────────────────┐ │
 │  │ ◌ Scanning…              │ │   danh sách máy tìm thấy, mỗi máy một dòng bấm được
 │  └──────────────────────────┘ │
 │  [ IP address      ] [ Port ] │   ô nhập lõm, viền sáng khi focus
 │  [ Pair port       ] [ Code ] │
 │  ( qr-code  QR code ) ( usb  USB ) │  2 nút phụ dạng viên, có icon Lucide
 │  (        Connect          ) │   nút chính viên xanh, đầy chiều ngang

```
- Dòng "* required. Press ? for setup help." bỏ; dấu * đổi thành chấm nhỏ cạnh nhãn.

### Màn hình chờ ("đêm Bắc Cực")
- Nền xanh đen tỏa sáng nhẹ ở giữa, vài chấm tuyết trắng rơi chậm.
- Cánh cụt trong huy hiệu tròn trắng-băng (vỏ kính mờ bên ngoài), nhún nhẹ; 2 vòng sóng xanh băng
  lan ra phía sau.

- 2 thẻ double-bezel ở đáy: iPhone (smartphone) "Screen Mirroring, then pick PhoneMimi";
  Android (usb) "Plug in a USB cable, or press A".
