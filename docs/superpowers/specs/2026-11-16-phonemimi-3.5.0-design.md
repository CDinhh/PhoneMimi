# PhoneMimi 3.5.0: drag and drop, clipboard sync, Android sound, cable setup guide

Date: 2026-11-16. Approved in chat by Định (with the changes below).

## Goals

1. **Drag and drop:** drop files on the window. `.apk` installs on the Android phone on screen (`adb install -r`), anything else goes to `/sdcard/Download/` (`adb push`). Several files run one after the other; progress and results show as toasts. Xiaomi's `INSTALL_FAILED_USER_RESTRICTED` gets the hint "turn on Install via USB in Developer options".
2. **Clipboard both ways, automatic:** phone copy lands in the PC clipboard (scrcpy device clipboard messages); PC text copy updates the phone clipboard without pasting. `Ctrl+V` still pastes. No echo loops (remember the last synced text); images on the PC clipboard are ignored.
3. **Android sound on the PC:** scrcpy audio (needs Android 11+). Default plays on **both** the PC and the phone (`audio_dup=true`, Android 13+; on 11 and 12 the sound moves to the PC). Settings > Phone gets "Mute phone speaker" (default off) which sets `audio_dup=false`; applies on the next connection like the other phone settings. Only the phone on screen is heard; `U` mutes the PC as before.
4. **Cable setup guide for non-technical users:** every 2 s the app reads Windows' list of USB devices (SetupAPI) and adb's list.
   - An Android phone (known USB vendor id) is plugged in but adb does not see it: the guide opens by itself with steps for the brand.
   - adb sees it as unauthorized: "Unlock the phone and tap Allow".
   - An iPhone is plugged in: "iPhone needs no cable: Control Center > Screen Mirroring > PhoneMimi".
   - The guide closes by itself once the phone connects. It is also the "?" in the Add Android panel; the old long help is removed.
   - Brand tabs: Samsung, Xiaomi, OPPO (top three Android brands, IDC Q3 2026), Other. Only what is needed; content from official sources:
     - Samsung (samsung.com, developer.android.com): Settings > About phone > Software information; tap Build number 7 times, enter PIN; Settings > Developer options > USB debugging.
     - Xiaomi (OS version entry verified on a HyperOS phone; "USB debugging (Security settings)" + restart from the scrcpy README): Settings > About phone; tap OS version 7 times; Settings > Additional settings > Developer options; USB debugging and USB debugging (Security settings), then restart.
     - OPPO (no official page loadable; path from community.oppo.com, consistent across sources): Settings > About device > Version; tap Build number 7 times; Settings > Additional settings > Developer options > USB debugging.
     - Other (developer.android.com): Settings > About phone; tap Build number 7 times; Settings > System > Developer options > USB debugging.
     - Footer: "Plug in the cable and tap Allow on the phone."
   - Same look as Settings: shell, round close button, segmented tabs, recessed card.
5. **Tooltips:** hover delay 1000 ms -> 300 ms.

## Design decisions (Claude's calls)

- Audio uses `audio_codec=raw` (PCM s16le 48 kHz stereo, ~1.5 Mbps): no decoder setup or Opus header handling; resampled to the 44.1 kHz output with a small linear resampler. SDK read with `getprop ro.build.version.sdk` before start: < 30 no audio, < 33 no `audio_dup`.
- Socket order with audio: video, audio, control.
- iPhone detection: vendor 05AC with product ids 0x1290-0x12AF (iPhones), so Apple keyboards do not trigger it.
- Pure logic (USB id parsing and the hint decision, device message parsing, resampler) lives in small files and is covered by `--mcp-self-test`.

Self-test cases: VID parse from `USB\VID_2717&PID_FF48\x`, decision table (debugging off / unauthorized / connected / iPhone / Apple keyboard), clipboard message split across reads, ACK and UHID messages skipped, resampler 4800 frames -> 4410 +-1.

3. App: audio routing (shown phone only), clipboard routing, drop handler worker, USB watch computing the setup hint every 2 s regardless of the auto-connect setting, SDK check.
4. Renderer: toasts from any thread, drop events, clipboard update event, setup guide panel (replaces old help), "Mute phone speaker" row, tooltip delay.
5. Settings field `android_mute_phone`; version 3.5.0; README + in-app history.
6. CI build, self-test, live test on the Xiaomi (drop an APK and a file, copy both ways, sound both sides and muted, guide by turning USB debugging off is not possible remotely: check the decision via logs).
